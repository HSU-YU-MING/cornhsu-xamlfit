# Font metrics and licensing: what we asked, and what we know

XamlFit needs to know how wide a character is. It gets those numbers from font files already
installed and licensed on the machine that runs `xamlfit fonts export`. Whether extracting such
numbers is permitted by the licence of a commercial font is a question we could not answer from
the published terms, so we asked. This page records what we asked, who we asked, and what came
back, so that anyone evaluating the tool can see the state of it rather than take a summary on
trust.

**This is not legal advice**, and none of it has been reviewed by a lawyer. It is a record of
correspondence and of what the published terms do and do not say.

## What is at stake

The metrics file (`xamlfit.fonts.json`, or `.json.gz`) is generated by the user, not shipped by
the project. The question is whether a user may:

1. extract these numbers from fonts licensed to their own machine, and
2. keep the resulting file in their own source repository, including a public one.

[THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md#font-metrics) lists every field the file holds.
In short: advance widths, kerning adjustments, vertical metrics, family names, and the widths that
the font's own substitution and positioning rules produce for complex scripts — all of them numbers
or names, keyed by Unicode code point. With `--hinted` it also holds the whole-pixel width GDI
reports for each character from 8 to 48 px.

It holds **no glyph outlines, no hinting instructions, no glyph IDs, and no copy of any font table
or of any font program**. The font files themselves are never copied or moved.

## What the published terms say

Microsoft's font redistribution FAQ (the version dated 2024-11-19, read on 2026-11-19) forbids
redistributing, modifying or converting the fonts that ship with Windows. It does not mention
metrics in any form. It directs extended licensing of Microsoft-owned fonts to Monotype, and
licensing questions about other fonts to the vendor named in the font's properties. It gives no
address for licensing questions.

We found no court decision on font metrics in either direction. The absence of a rule is not
permission, which is why we asked rather than assumed.

## The five questions

Sent in these words:

1. Does the license of the fonts included with Windows permit an end user to extract such metrics
   from their own installed fonts and keep them in their source repository?
2. Does the answer change if that repository is **public**?
3. If a public repository is not acceptable, is it acceptable for the user to generate the metrics
   during a continuous-integration run on a licensed Windows machine and discard them afterwards,
   without storing them anywhere?
4. The FAQ says Segoe UI Variable is not available for use outside Microsoft products. Should its
   metrics be treated differently? (Our tool now leaves it out unless the user names it explicitly.)
5. If none of the above is acceptable, is there a license or program under which this use would be?

## What happened

| Date (2026) | What |
|---|---|
| 11-19 | The fonts.com page the FAQ links to now redirects to a MyFonts licensing enquiry form. The form collects a name, an email, a country and a list of fonts; it has no free-text field, so the questions could not be asked there. Submitted it naming Segoe UI and Microsoft JhengHei UI. |
| 11-19 | MyFonts support replied asking what the fonts would be used for. Answered each point, then sent the five questions above, asking that they be passed to Microsoft or to the licensing team if support could not answer them. |
| 11-19 | Support replied that the enquiry had been forwarded to Monotype's sales team, and that a sales representative would be in touch. |
| 11-23 | Support wrote again with the same request for contact details that had already been answered on 11-19, without saying what was missing and without answering any question. Answered again. |
| 11-24 | A Monotype licensing representative wrote, asking to be telephoned to discuss the matter. **None of the five questions was addressed.** |
| 11-25 | Replied in writing: restated the five questions, explained that the answer has to be something the project can quote in its documentation, and offered a call once there is a written answer. |

**Current status: no answer to any of the five questions.** This page will be updated when one
arrives, whatever it says. If the answer is that this use is not permitted, the tool's defaults and
its recommendations will change to match, and that change will be recorded here too.

## What the tool does in the meantime

These are the precautions the project takes while the question is open. They are deliberately on
the conservative side.

- **The package ships metrics for no proprietary font.** The demo project's metrics come from a
  synthetic font generated by `prototype/DemoMetrics`, not from any real font.
- **Segoe UI Variable is skipped** unless the user names it with `--family`, because the FAQ says it
  is not available for licensing or use outside Microsoft products.
- **The file records only the installed family names that name resolution needs** — the exported
  families, and installed families whose names begin with one of them — not an inventory of what is
  installed on the machine that exported it.
- **For a public repository, the README recommends generating the file during the CI run** instead
  of committing it, and not uploading it as a workflow artifact, because a public repository's
  artifacts can be downloaded.
- **For a private repository**, the file stays inside the boundary where the fonts' own licence
  already applies.

## If you are evaluating this for an organisation

The position above is a maintainer's reading of published terms plus an unanswered enquiry. It is
not a warranty, and nothing here transfers any right in any font to anyone. If your organisation
needs certainty, the two things that give it are your own counsel's reading of the font licences
you hold, and a written answer from the licensor for your use. If you obtain one, we would be glad
to link it here.
